Prepare Data: python src/unify_datasets.py

Train Ultrasound Expert:
python src/train.py --mode us

Train Mammography Expert:
python src/train.py --mode mg

Generate Final Report Stats:
python src/evaluate.py

Launch the Demo:
streamlit run app.py
